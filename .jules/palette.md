## 2024-05-18 - [Accessibility Improvement: Chatbot Toggle]
**Learning:** Dynamic UI components like floating action buttons (FABs) that toggle state must include robust ARIA linkage (`aria-expanded` and `aria-controls`) and visible focus indicators. Standard `get_by_role` locators in Playwright may struggle with dynamically updating attributes; using specific attribute locators (e.g., `[aria-label="..."]`) provides more reliable test execution.
**Action:** When implementing or updating togglable UI elements, always generate a unique ID (e.g., using `useId()` in React), link the button to the content via `aria-controls`, reflect the state with `aria-expanded`, and ensure focus visibility (`focus:ring`). During verification, use attribute-specific locators if role-based selection times out.
