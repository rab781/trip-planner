# Documentation

Welcome to the documentation for the Itinerary Management System. Our documentation follows the Divio Documentation System, organizing content into four distinct types:

- **Tutorials**: Step-by-step learning-oriented lessons.
- **How-Tos**: Problem-oriented guides for achieving specific goals.
- **Reference**: Information-oriented technical descriptions (like API endpoints).
- **Explanation**: Understanding-oriented discussions on concepts and background.

## Getting Started

Check out our tutorials to get started quickly, or consult the reference for detailed API information.
