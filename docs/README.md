# Itinerary Management System Documentation

Welcome to the official documentation for the Itinerary Management System. This documentation is structured following the [Divio Documentation System](https://documentation.divio.com/), organized into four distinct types of content.

## 📚 Documentation Structure

### [Tutorials](./tutorials/)
**Learning-oriented**: Step-by-step guides that teach you how to achieve a specific goal from scratch. Best for beginners.
- [Build Your First AI Itinerary in 15 Minutes](./tutorials/build-first-itinerary.md)

### [How-To Guides](./how-to/)
**Task-oriented**: Practical instructions to solve specific problems or complete particular tasks.
- [Set Up AI Features](./how-to/setup-ai-features.md)

### [Reference](./reference/)
**Information-oriented**: Technical descriptions, API details, and configurations. Focused on accuracy and completeness.
- [API Reference](./reference/api.md)

### [Explanation](./explanation/)
**Understanding-oriented**: High-level overviews of system architecture, design decisions, and concepts.
- [The AI Itinerary Engine](./explanation/ai-itinerary-engine.md)

## Contributing to Docs

We treat documentation bugs as seriously as code bugs. When contributing:
1. Ensure all code examples run and are tested.
2. Maintain a consistent voice (second person "you", present tense).
3. Do not assume context; link out to prerequisites.
